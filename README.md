# Customer Behavior Data Analysis

## Project Overview
This project focuses on analyzing customer shopping behavior to understand purchasing patterns, customer preferences, sales performance, and discount trends. Using Python, MySQL, and Power BI, this end-to-end data analytics workflow explores transactional shopping data to uncover actionable business insights.

## Tools & Technologies
- **Python:** Data cleaning, preprocessing, and exploratory data analysis (EDA).
- **MySQL:** Data querying and business metric analysis using SQL.
- **Power BI:** Interactive data visualization and dashboard reporting.
- **Jupyter Notebook:** Python development and documentation environment.

## Dataset
The project uses the `customer_shopping_behavior.csv` dataset, which contains customer demographics, purchase details, product categories, review ratings, discount usage, shipping methods, and subscription status.

## Key Analysis Performed
- **Revenue & Spending:** Revenue breakdown by gender, age group, and average purchase amount.
- **Product Performance:** Top 3 products by category and overall product rating analysis.
- **Customer Behavior:** Customer segmentation (New, Returning, Loyal), repeat customer trends, and subscription status impact.
- **Promotions & Logistics:** Discount rate effectiveness and shipping type comparisons.

## Project Files
- `customer_shopping_behavior.csv` – Raw transactional dataset.
- `.ipynb` – Jupyter Notebook containing Python data cleaning and EDA.
- `.sql` – MySQL queries used for data aggregation and analysis.
- `.pbix` – Interactive Power BI dashboard file.

## Key Skills & Outcomes
- Executed end-to-end data cleaning and exploratory data analysis using Python.
- Wrote advanced SQL queries in MySQL Workbench utilizing aggregations, filtering, CTEs, and window functions.
- Uncovered actionable customer purchasing and retention patterns.
- Designed and built an interactive Power BI dashboard to communicate key KPIs.
