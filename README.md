# Customer Behavior Data Analysis

## Project Overview
This project focuses on analyzing customer shopping behavior to understand purchasing patterns, customer preferences, sales performance, and discount trends.

The project uses Python, MySQL, and Power BI to explore customer shopping data and generate meaningful business insights.

## Tools & Technologies
- **Python:** Data cleaning and exploratory data analysis.
- **MySQL:** Data analysis using SQL queries.
- **Power BI:** Data visualization and dashboard.
- **Jupyter Notebook:** Python development environment.

## Dataset
The project uses the `customer_shopping_behavior.csv` dataset containing customer information, purchase details, product categories, ratings, discounts, shipping types, and subscription status.

## Key Analysis Performed
- Revenue analysis by gender.
- Average purchase amount analysis.
- Product rating analysis.
- Shipping type comparison.
- Subscription status analysis.
- Customer segmentation (New, Returning, Loyal).
- Top 3 products by category.
- Discount rate analysis.
- Repeat customer analysis.
- Age-group revenue analysis.

## Project Files
- `customer_shopping_behavior.csv` – Dataset.
- `.ipynb` – Python notebook.
- `.sql` – SQL analysis queries.
- `.pbix` – Power BI dashboard.

## Learning Outcomes
- Practiced data cleaning and exploratory data analysis.
- Learned SQL aggregation, filtering, CTEs, and window functions.
- Explored customer purchasing patterns.
- Gained experience with Power BI dashboards.
